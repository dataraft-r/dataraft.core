# dataraft.core

Define products and contracts, prepare data with recipes, and run checked workflows in memory. Use `library(dataraft.core)`; lake, catalog and dbt packages are not required.

This is an independently installable DataRaft component. The `dataraft`
metapackage provides the shared introduction and re-exports the family API.
See `help(package = "dataraft.core")` for the component reference.

Install the development version:

```r
install.packages("pak")
pak::pak("dataraft-r/dataraft.core")
```

[Get started with DataRaft](https://github.com/dataraft-r/dataraft).
